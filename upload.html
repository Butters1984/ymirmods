Upload Requirements

  • You must be logged into a YMIR account.
  • Your account must have uploader permission.
  • Mod package must be a ZIP file.
  • Use a clear version number such as 1.0.0.
  • Icons should ideally be square.

What Happens Next?

The ZIP and icon are stored in YMIR's R2 storage.

The mod's name, version, description, category, file location and changelog are saved into D1.

Next we'll create proper public mod pages so uploaded mods automatically appear on the main website.
